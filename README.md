# EBS Contrôle NIBT

Assistant terrain mobile pour les contrôles d'installations électriques selon la NIBT SN 411000:2025.

Outil interne développé par **Eric Arm**, ingénieur HES/ETS en génie électrique
**EBS Engineering & Building Solutions Sàrl** — Ogens, Vaud, Suisse

## Caractéristiques

- Web app installable (PWA) — fonctionne hors-ligne après première visite
- Optimisée smartphone Android / iPhone
- Capture photo via caméra ou galerie
- Analyse assistée par IA (API Anthropic Claude)
- Mode normatif strict ou pédagogique
- Génération de rapports PDF
- Envoi par email
- Aucune donnée serveur : tout reste dans le navigateur du contrôleur

## Utilisation

Application accessible sur : https://earmfordocabb.github.io/ebs-controle/

Une clé API Anthropic personnelle est requise pour activer les analyses.
Elle est stockée uniquement dans le navigateur local de l'utilisateur.

## Cadre normatif de référence

- NIBT SN 411000:2025
- OIBT (RS 734.27), LIE (RS 734.0)
- Directives ESTI, AEAI, SUVA
